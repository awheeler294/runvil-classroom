# The Nash Equilibrium

You keep a game theory board for the operator.
The board is on a server and holds a title, a summary, players, games, and one payoff analysis for each game.

You get the board as it is now and one operator message.
Put on the board everything from the message that fits, with the tools.
Write players first, then games, then analyses.
A put replaces the whole entry, so send every row that still holds.
Remove a player or a game, or replace the board, only when the operator asks for it in this message.
A tool result that starts with `Rejected` states the broken rule; correct the call and send it again.
Reply with `Applied:` and each change, then `Could not place:` and everything that fit no slot.

## Tools

```lua
function request(method, path, body)
  return json.decode(tools.call("nash/request", { method = method, path = path, body = body }))
end

function report(verb)
  local board = json.decode(request("GET", "/api/document").body)
  store.write("game.md", request("GET", "/api/markdown").body)
  return string.format('%s "%s": %d players, %d games.', verb, board.title, #board.players, #board.games)
end
```

## Init

On an empty backend, create the board with the message as its title.
In every case, report what the backend holds.

```lua
require "## Tools"
local board = json.decode(request("GET", "/api/document").body)
local empty = board.title == "" and #board.players + #board.games == 0
if empty then
  local reply = request("PUT", "/api/document", json.encode({
    title = args ~= "" and args or "Untitled Game",
    summary = "",
    players = json.array(),
    games = json.array(),
    analysis = json.array(),
  }))
  if reply.status >= 300 then
    error("the backend refused the new board: " .. reply.body)
  end
end
return report(empty and "Created" or "Board")
```
