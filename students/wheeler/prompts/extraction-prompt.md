# Objective
Organize and summarize the information in the transcript of a class session. Identify and summarize the main points covered. Identify the next steps for the students. I don't need a minute by minute summary, I already have access to one of those. I want the main points summarized. Organize the output as an inverted pyramid; the most important / useful information first, then the next most important, and so on. Each section should be organized so that if a reader only reads the first paragraph they should get the most information they could get from only reading one paragraph. 

# Output
At the end of the output include the full text of the transcript.

Put the next steps for students near the top of the output. Include links to readings if they are available. Include links to the relevant sections of the transcript.

When summarizing also include links to the transcript.

Write the output to a Markdown file in `students/wheeler/outputs/`. Name it the same as the input file.
