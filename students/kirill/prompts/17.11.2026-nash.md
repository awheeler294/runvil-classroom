Point this tool at a board server.
It maintains a structured game board - players, moves, payoffs, sequential games - one message at a time.
You talk, it compresses what you said into the board schema.
On command, it shows the board or adds an empty player or game, without a model.
The board format is inviolable.

Each message is one run:

- On an empty board, the message becomes the board's title.
- No message, `show state`, `add player <name>`, and `add game <name>` run without a model.
- Anything else goes to the model, which edits the board through the server's API.
- `test me` loads the Prisoner's Dilemma.

```lua
if args.text == "test me" then
  jump("../Test")
end
```

## Init

On an empty backend, ask for a title, or create the board with the message as its title and announce it.
A command is never a title.

```lua
require "/Tools"
local current = board()
if current.title == "" and #current.players + #current.games == 0 then
  local text = args.text or ""
  if text:match("^%s*$") or command(text) then
    return "The board is empty; send its title to create it."
  end
  local reply = request("PUT", "/api/document", json.encode({
    title = text,
    summary = "",
    players = json.array(),
    games = json.array(),
    analysis = json.array(),
  }))
  if reply.status >= 300 then
    error("the backend refused the new board: " .. reply.body)
  end
  return "Created " .. summary()
end
```

## Commands

Answer the commands that need no model, and touch nothing else.
With no message, announce the board's player and game counts.
`show state` prints the board as it is.
`add player <name>` and `add game <name>` add an empty entry, and leave an existing one as it is.
A name of more than four words, or one with punctuation, goes to the model instead.

```lua
require "/Tools"
local text = args.text or ""
if text:match("^%s*$") then
  return "Loaded " .. summary()
end
local action, kind, name = command(text)
if action == "show" then
  return report()
end
if action == "add" then
  local plural = kind .. "s"
  for _, entry in ipairs(board()[plural]) do
    if entry.name == name then
      return string.format("The %s %s already exists; nothing changed.", kind, name)
    end
  end
  local empty = kind == "player"
    and { summary = "", games = json.array(), moves = json.array(), outcomes = json.array() }
    or { trigger = "", players = json.array(), steps = json.array() }
  local reply = request("PUT", "/api/" .. plural .. "/" .. encode(name), json.encode(empty))
  if reply.status >= 300 then
    return string.format("Could not add the %s %s: %s", kind, name, reply.body)
  end
  return string.format("Added the %s %s to %s", kind, name, summary())
end
```

## Edit

You keep a game theory board for the operator.
The board is on a server and holds a title, a summary, players, games, and one payoff analysis for each game.

You get the board as it is now, the server's API, and one operator message.
Put on the board everything from the message that fits, with the request tool.
Write players first, then games, then analyses.
A put replaces the whole entry, so send every row that still holds.
Remove a player or a game, or replace the board, only when the operator asks for it in this message.
A result with a status of 400 or more was rejected, and its body states the broken rule; correct the call and send it again.
Reply with `Applied:` and each change, then `Could not place:` and everything that fit no slot.

```lua
require "/Tools"
tools.offer("nash")

messages:system(prose)
messages:system("The server's API, as OpenAPI JSON:\n" .. request("GET", "/api/openapi.json").body)
messages:user("The board now:\n\n" .. report() .. "\n\nThe operator's message:\n\n" .. args.text)
models.loop()
return messages[#messages].content .. "\n\n" .. report()
```

## Tools

```lua
function request(method, path, body)
  return json.decode(tools.call("nash/request", { method = method, path = path, body = body }))
end

function report()
  return request("GET", "/api/markdown").body
end

function board()
  return json.decode(request("GET", "/api/document").body)
end

function summary()
  local current = board()
  local function count(number, noun)
    return number .. " " .. noun .. (number == 1 and "" or "s")
  end
  return string.format('"%s": %s, %s.', current.title,
    count(#current.players, "player"), count(#current.games, "game"))
end

function command(text)
  if text:lower():match("^%s*show%s+state%s*$") then
    return "show"
  end
  local verb, kind, name = text:match("^%s*(%a+)%s+(%a+)%s+(.-)%s*$")
  if not verb or verb:lower() ~= "add" or name:find("[:,;%.!%?%(%)]") then
    return nil
  end
  kind = kind:lower()
  local words = select(2, name:gsub("%S+", ""))
  if (kind == "player" or kind == "game") and words >= 1 and words <= 4 then
    return "add", kind, name
  end
end

function encode(text)
  return (text:gsub("[^%w%-%._~]", function(symbol)
    return string.format("%%%02X", symbol:byte())
  end))
end
```
