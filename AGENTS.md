* "Runvil" is the spelling
* Runvil is a prompting engine with a harness
* Runvil Workshop is a VSCode/Cursor style IDE which can run Runvil prompts
* Runvil Gateway is a proxy server for local and remote inference resources
* This repository never uses pull requests. Every change is merged directly: commit on `master` and push it to `master` of `cppalliance/runvil-classroom`
